# Benchmark logs

Each file is one measured run on a single AWS Trainium2 chip with tensor parallelism over
two NeuronCores, one request at a time, greedy decoding, three prompts repeated twice, and
128 generated tokens per request.

- `bench_baseline.txt`: no speculative decoding; 2026-10-10 22:43 UTC.
- `bench_dflash_k{2,4,8}_causal.txt`: original causal query-block mask.
- `bench_dflash_k{2,4,8}_bidirectional.txt`: all-ones active mask within the draft query block.
- `bench_dflash_k15_causal.txt`: causal only; bidirectional k=15 was not measured.

The baseline log is the 2026-10-10 22:43 UTC run. Its body is the captured terminal output of
that run. The capture omitted the first header line, so that line was restored from what
`run_bench.sh` wrote at the time. Its mean is 51.7 tok/s, and all reported speedups use that value.

The first line of each log records `mask_mode` and whether `bidirectional_attention.patch` was
installed. The runs predate that header, so it was added afterwards from the build used for
each run; measured output and counters are unchanged.

`throughput.svg` and `acceptance.svg` are generated by `../make_charts.py`. The GitHub Pages
site is generated independently from the same logs by `../make_dashboard.py`.
